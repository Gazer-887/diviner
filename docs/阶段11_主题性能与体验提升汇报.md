## 二、核心改动（改前 → 改后）

### 2.1 P0 · 性能（`globals.css`）

| 项 | 改前 | 改后 |
|---|---|---|
| 星带（star） | `body::after` 第 4 层背景 + `star-river` 60s `background-position` 平移 | 迁至新增 `html::before` 固定漂移层，`star-river` 改 `transform: translate3d(360px,360px,0)` |
| 柳絮（chun） | 同上，`willow-drift` 14s `background-position` | 迁至 `html::before`，`transform: translate3d(320px,320px,0)`，周期调 18s 保持原速率 |
| 蝴蝶振翅（chun） | 动 `background-size`（120→115px，同样整屏重绘） | 独立 `html::after` 120×120 小块，`scaleX(1→0.93)` 呼吸 |
| 无缝衔接 | 原 keyframes 终点 120px 非 tile 整数倍，存在周期跳变 | 位移量取整 tile + 元素外扩 `inset:-400/-360px`，首尾无缝且边缘不露白 |

新增动态层默认 `display:none`，由主题按需启用；`body::before`（光晕）与 `body::after`（静态纹理）保持不动，静态纹理不再参与任何动画。

### 2.2 P2 · 移动端归位

`@media (max-width: 640px)` 内动态层统一 `animation:none; transform:none; opacity:0.4`——不管进入小视口时动画播到哪一帧，背景都回到初始构图。

### 2.3 P1 · 辨识度（过渡 > 字体 > 形状）

| 主题 | 标题字族（`--font-serif`） | 卡片轮廓 | 备注 |
|---|---|---|---|
| 月明青山 star | 宋体族（维持） | `border-radius: 22px` | 夜色柔和 |
| 红豆生思 zen | 楷体族（Kaiti/STKaiti/KaiTi 优先） | `6px` | 笔锋贴水墨 |
| 似天在水 cyb | 几何无衬线（PingFang/HarmonyOS/雅黑） | `2px` + 内嵌青色细描边（`::before` 双线） | 弃 clip-path 折角，避免裁掉 hover 外发光 |
| 昔我往矣 chun | 圆体族（Yuanti/YouYuan 优先） | `26px` | 花瓣柔边 |

- **换肤淡入**：新增 `deco-fade-star/zen/cyb/chun` 四套 keyframes（0.45s）。只写 `from{opacity:0}`、终点取元素计算值——否则 `animation-fill-mode` 会把移动端 `opacity:0.4` 盖成桌面值。四套名字不同是因为同一元素想重新播动画必须让 `animation-name` 发生变化。
- **字体全部系统字族**：无 `@font-face`、无网络请求、无加载报错风险。

### 2.4 P2 · 按压态

`.wb-card / .wb-card-hover` 补 `:active { transform: translateY(-1px) scale(0.99); transition-duration: 0.12s }`，置于 hover 规则之后保证优先级；金/墨/青/粉 hover 辉光原样保留。
